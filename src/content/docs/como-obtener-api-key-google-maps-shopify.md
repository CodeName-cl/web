Te mostramos cómo conseguir una clave API para activar el autocompletado de direcciones en tu tienda Shopify.

Para usar esta función, primero instala nuestra app <a href="https://apps.shopify.com/validador-de-direcciones">LocFix AI</a>.

## Guía paso a paso

Si no tienes cuenta en Google Cloud, crea una desde la <a href="https://console.cloud.google.com/">consola de Google Cloud</a>.

1. Escribe "maps API" en el buscador.
![Buscar maps API](/docs/como-obtener-api-key-google-maps-shopify/image-5.png)

2. Busca "Maps Embed API" y haz clic en "Keys".
![Maps Embed API Keys](/docs/como-obtener-api-key-google-maps-shopify/image-6.png)

3. Haz clic en "Create credentials".
![Create credentials](/docs/como-obtener-api-key-google-maps-shopify/image-7.png)

4. Luego elige "API Key".
![Elegir API Key](/docs/como-obtener-api-key-google-maps-shopify/image-8.png)

5. Copia la clave que aparece.
![Copiar clave API](/docs/como-obtener-api-key-google-maps-shopify/image-9.png)

Tu API Key es como una contraseña: guárdala con cuidado.

Consulta los <a href="https://mapsplatform.google.com/pricing">costos de uso aquí</a> y revisa la <a href="https://developers.google.com/maps/documentation/embed/get-api-key">documentación oficial</a> para más detalles.
